# Agent Skills

Each folder below contains a `skill.md` with step-by-step instructions for a specific workflow. Read the appropriate skill before starting work.

## Available Skills

| Skill | Folder | When to Use |
|-------|--------|-------------|
| Deploy | `deploy/` | Build, test, and deploy to Cloudflare Pages |
| New Component | `new-component/` | Create a new React component following project patterns |
| New Page | `new-page/` | Add a new routed page with lazy loading |
| Add Product | `add-product/` | Add a single product to the catalog |
| Email Template | `email-template/` | Create or modify branded email templates |
| Content Update | `content-update/` | Update hero text, about page, services, SEO metadata |
| Product Catalog | `product-catalog/` | Bulk product operations, categories, pricing |
| Contact Form | `contact-form/` | Modify the contact form fields or API behavior |

## How It Works

1. Identify which workflow matches the task
2. Read the `skill.md` in that folder
3. Follow the steps — each skill ends with verification steps
4. Skills may reference each other (e.g., after adding a product, use `deploy/` to ship it)

Helper files like templates are co-located in each skill folder when needed.
